# Historical archive

Nothing under `archive/` is imported or executed by the four-experiment evaluation runner.
These files are retained to preserve the complete scientific audit trail.

- `exploratory/` contains hypothesis-development packages, scripts, tests,
  specifications, and the PRD scratchpad.
- `deprecated/` contains superseded duplicate implementations, especially the
  two partial-observability GRU generations.
- `old_outputs/` contains verification, smoke, superseded, and exploratory
  result directories.

`research_history/` preserves the former root PRDs, scratch reports, README, and copies of the old paper runners. `artifact_index.json` records old and new paths, SHA256 hashes, reasons, and paper dependencies. The current analysis path is documented in the root `README.md` and `docs/analysis_contract.md`. Historical outputs are used only when the current paper contract explicitly names and hashes them.
