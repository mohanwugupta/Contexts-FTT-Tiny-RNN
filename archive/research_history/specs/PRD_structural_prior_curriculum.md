# PRD: Curriculum for Learning a Structural Generalization Prior in SRNs

## 0. Purpose

The previous hierarchical/compositional pretraining experiment stopped at the internal pilot gate because the structured ecology (P2) did not outperform the matched shuffled ecology (P1) on the two frozen internal generalization criteria. The human-task transfer phase was therefore correctly not run.

This PRD tests a narrower hypothesis:

> The 8-unit SRN may be capable of learning a useful structural prior, but the previous ecology was too abstract because the mapping between visible context factors and task factors changed almost arbitrarily across worlds.

The goal is therefore to **curriculum-learn the prior**, starting from a deliberately easy ecology with stable factor semantics and then progressively removing scaffolding.

The key scientific question is:

\[
\boxed{\text{What is the most abstract contextual ecology under which the SRN can still learn compositional reuse?}}
\]

Only after that question is answered should the successful pretrained checkpoint be transferred to the human A/B task.

---

# 1. Core design

Use four increasingly abstract pretraining ecologies:

| Stage | Name | Stable across worlds | Variable across worlds | Purpose |
|---|---|---|---|---|
| E0 | Deterministic compositional | factor semantics + factor→task mapping | sequence instances | Can the SRN learn compositional reuse at all? |
| E1 | Surface-varied | latent factor semantics + factor→task mapping | cue/layout surface realization | Can it generalize across appearance? |
| E2 | Factor-permuted | relational factor structure | which visible feature instantiates each factor | Can it learn a more abstract prior? |
| E3 | Fully abstract | only second-order relation | visible factors + task-factor identities | Reproduce prior difficult ecology |

The pipeline must be **sequentially gated**:

```text
E0 must pass before E1
E1 must pass before E2
E2 must pass before E3
```

Do not run later stages if an earlier stage fails.

---

# 2. Fixed architecture

Use the same learner throughout:

```text
8-unit tanh Elman SRN
High initialization scale = 2.0
same next-token prediction head
same monotonic execution readout
same optimizer family
same execution objective
```

Do not add:

```text
attention
retrieval layers
latent-context modules
larger hidden size
extra supervised losses
```

This experiment manipulates only **prior experience / ecology structure**.

---

# 3. Common synthetic task format

Each world contains:

```text
sequence length = 8
response alphabet = 4
two binary contextual factors
four possible factor combinations
```

Let:

\[
c=[c_1,c_2], \qquad c_j\in\{0,1\}.
\]

Each factor controls a fixed sparse subset of transition positions.

Primary assignment:

```text
factor 1 -> transitions P2 and P3
factor 2 -> transitions P5 and P6
```

All remaining positions follow the shared family backbone.

This creates:

\[
\theta_c=\theta_{shared}+c_1\Delta_1+c_2\Delta_2.
\]

The task modifiers must be compositional:

```text
Delta_1 affects only P2/P3
Delta_2 affects only P5/P6
```

When both factors are active, both modifiers apply.

No arithmetic averaging target is used.

---

# 4. Within-world train/test structure

For every world:

Train on exactly three contexts:

```text
[0,0]
[1,0]
[0,1]
```

Freeze-test:

```text
[1,1]
```

The held-out [1,1] target is generated by applying both independently defined task modifiers.

Thus successful transfer requires reuse of both learned factors.

This is a compositional generalization test, not a midpoint test.

---

# 5. E0 — Deterministic compositional ecology

## 5.1 Goal

Establish whether the current SRN can learn compositional reuse under the easiest plausible ecology.

## 5.2 Stable factor semantics

Across every world:

```text
visible factor dimension 1 always corresponds to task modifier Delta_1
visible factor dimension 2 always corresponds to task modifier Delta_2
```

The factor-to-task-position mapping remains fixed:

```text
factor 1 -> P2/P3
factor 2 -> P5/P6
```

## 5.3 Observable context

Use two explicit but ordinary contextual input channels:

```text
z = [c1, c2]
```

Optionally append these to the same cue input block used by the SRN.

Do not give symbolic labels such as:

```text
"factor 1"
"factor 2"
"compose"
```

## 5.4 What changes across worlds

Randomize:

```text
base 8-item sequence
specific response remappings produced by Delta_1
specific response remappings produced by Delta_2
world order
```

But preserve factor semantics.

## 5.5 E0 success criterion

Structured training must beat the matched shuffled control on held-out [1,1] generalization.

Primary metrics:

```text
held-out prediction NLL
held-out next-token accuracy
```

Pass only if:

```text
mean NLL_structured < mean NLL_shuffled
AND
mean accuracy_structured >= mean accuracy_shuffled
```

with the NLL difference in the expected direction for at least 4/5 pilot seeds.

---

# 6. E0 shuffled control

Construct a matched shuffled ecology.

For each generated structured world:

1. Preserve:
   ```text
   base sequence
   visible context vectors
   task modifiers
   number of updates
   difficulty
   ```
2. Randomly permute the context-to-task-modifier mapping for the training contexts.
3. Keep the held-out probe generated from the unshuffled latent task definition.

The shuffle must destroy the stable relation:

\[
c_j\rightarrow\Delta_j
\]

while preserving all marginals.

This is the causal control for learning the structural rule.

---

# 7. E1 — Surface-varied ecology

Run only if E0 passes.

## 7.1 Goal

Test whether the learned prior survives changes in perceptual surface form.

## 7.2 Stable semantics

Still preserve:

```text
latent factor 1 -> Delta_1
latent factor 2 -> Delta_2
```

and:

```text
Delta_1 -> P2/P3
Delta_2 -> P5/P6
```

## 7.3 Vary observable realization

Instead of direct:

```text
[c1, c2]
```

generate:

\[
z=W_wc+b_w
\]

where:

```text
W_w changes across worlds
b_w changes across worlds
```

but the transformation is constrained to preserve factor identity.

Primary implementation:

```text
factor 1 always projects mostly onto observable subspace A
factor 2 always projects mostly onto observable subspace B
```

Example:

```text
z has 6 dimensions
dims 1-3 mainly encode factor 1
dims 4-6 mainly encode factor 2
```

Randomize values within those subspaces across worlds.

This makes surface cues variable while preserving stable latent semantics.

## 7.4 Success criterion

Same frozen held-out [1,1] test and Structured > Shuffled requirement as E0.

---

# 8. E2 — Factor-permuted ecology

Run only if E1 passes.

## 8.1 Goal

Test whether the network can abstract beyond fixed observable subspaces.

## 8.2 Stable relational structure

The world still contains two reusable factors:

```text
factor A modifies one sparse transition subset
factor B modifies another sparse transition subset
```

But their observable channels are permuted across worlds.

Example:

```text
world 1: factor A -> cue dims 1-3
         factor B -> cue dims 4-6

world 2: factor A -> cue dims 4-6
         factor B -> cue dims 1-3
```

Also allow sign flips / affine surface transformations.

## 8.3 Still preserve task-factor semantics

Do not yet randomize which transition subset each latent factor controls.

Keep:

```text
factor A -> P2/P3
factor B -> P5/P6
```

The challenge is perceptual binding, not arbitrary task-role reassignment.

## 8.4 Success criterion

Same held-out compositional generalization gate.

---

# 9. E3 — Fully abstract ecology

Run only if E2 passes.

## 9.1 Goal

Reintroduce the difficult condition that likely caused the previous pilot failure.

Across worlds, randomize:

```text
observable factor realization
which factor controls which sparse transition subset
specific task modifiers
```

The only stable rule becomes:

\[
\text{shared latent factor}\Rightarrow\text{reusable task component}.
\]

This is the closest version to the previous hierarchical/compositional ecology.

## 9.2 Interpretation

If E0-E2 pass but E3 fails:

> The SRN can learn a structural prior when some factor semantics remain stable, but cannot meta-learn a completely abstract factor-to-task binding rule with fixed-weight SGD.

That is an informative architectural limit.

---

# 10. Training schedule

## Pilot per ecology

Run:

```text
5 paired seeds
100 worlds
```

for:

```text
Structured
Shuffled
```

Use paired world generation.

If a stage passes, run confirmatory:

```text
20 paired seeds
1000 worlds
```

before advancing.

Do not inspect the human Mixed/Novel task during ecology selection.

---

# 11. World training protocol

Within each world:

```text
10 sequences per observed context
3 observed contexts
30 training sequences total
```

Recommended order:

```text
randomized blocks, balanced across [0,0], [1,0], [0,1]
```

Then run frozen [1,1] probe.

No optimizer update on the held-out context.

At world transition:

```text
reset hidden state
retain network weights
retain optimizer state during pretraining
```

---

# 12. Internal learning diagnostics

For every world and seed save:

```text
training NLL by context
training accuracy by context
held-out [1,1] NLL
held-out [1,1] accuracy
factor-specific transition accuracy
shared-transition accuracy
```

Critical diagnostic:

For held-out [1,1], separately score:

```text
P2/P3 positions controlled by factor 1
P5/P6 positions controlled by factor 2
shared positions
```

This tells us whether the network truly combines factor-specific knowledge rather than succeeding only on shared positions.

---

# 13. Stronger compositional success metric

Define:

\[
G_{comp}
=
\frac{1}{4}
\sum_{k\in\{P2,P3,P5,P6\}}
\mathbb{1}[\hat y_k=y_k^{true}].
\]

Primary compositional metric:

```text
held-out modified-position accuracy
```

Require Structured > Shuffled.

This should be reported alongside overall accuracy because shared positions can otherwise inflate performance.

---

# 14. No-human-task firewall

Until an ecology stage passes the full confirmatory gate:

```text
do not run human A/B training
do not compute Mixed
do not compute Novel
do not inspect corridor metrics
```

The prior must first demonstrate that it exists internally.

---

# 15. Selecting the transfer checkpoint

After curriculum testing, choose the **most abstract ecology that passes**.

Examples:

```text
E0 passes, E1 fails -> transfer E0
E0/E1 pass, E2 fails -> transfer E1
E0/E1/E2 pass, E3 fails -> transfer E2
all pass -> transfer E3
```

Do not choose based on human probe results.

Use the final pretrained checkpoint from the passing ecology.

---

# 16. Human-task transfer phase

Only after selecting the most abstract passing ecology.

Compare three groups:

```text
H0 = random-init baseline
H1 = shuffled-pretrained control from same ecology level
H2 = structured-pretrained checkpoint
```

Then train all groups identically on:

```text
G2_shared_x
A10/B10
170 external sequences
High scale task
same optimizer reset
same learning rate
same monotonic RT mapping
```

No Mixed/Novel training.

---

# 17. Human-task familiar gates

Before interpreting transfer, require H2 to preserve:

```text
A/B sequence learning
A/B hidden differentiation
context-yoked RT dynamics
majority Cross/Split phenotype
negative confidence->RT slope
```

Transfer improvement caused by collapse toward Lump is a failure.

# 18. Human-task primary outcomes

## Mixed

Primary:

```text
first-probe between-endpoint fraction
```

Secondary:

```text
Mixed NLL deficit over worse endpoint
Mixed RT deficit over worse endpoint
```

## Novel

Primary:

```text
Novel NLL deficit over worse endpoint

```

```text
Novel between-endpoint fraction

```

# 19. Human transfer success criterion

The strongest result is:

```text
H2 > H1 and H0 on first-probe Mixed interpolation
```

while:

```text
A/B differentiation is preserved
```

```text

```

```text

or

```

# 24. Interpretation matrix

## Outcome A — E0 fails

Interpretation:

> The current 8-unit SRN/objective cannot learn even a simple compositional reuse rule from pretraining.

Do not continue to richer ecologies.

This would strongly motivate changing architecture or training objective rather than ecology.

## Outcome B — E0 passes, E1 fails

Interpretation:

> The SRN can memorize stable factor semantics but cannot generalize the rule across variable perceptual realizations.

## Outcome C — E0-E1 pass, E2 fails

Interpretation:

> Stable latent factor identity is required; flexible perceptual binding is the bottleneck.

## Outcome D — E0-E2 pass, E3 fails

Interpretation:

> The SRN learns reusable structural priors when factor semantics remain partially stable, but does not meta-learn arbitrary factor-to-task relations.

This is a plausible psychologically meaningful regime.

## Outcome E — All stages pass

Interpretation:

> The simple SRN can acquire a highly abstract compositional prior purely from experience.

Transfer E3 to the human task.

## Outcome F — A passing ecology improves first human Mixed probe

Interpretation:

> Prior structured experience can explain immediate recombination without explicit averaging.

## Outcome G — Internal prior is learned but human transfer still fails

Interpretation:

> Compositional reuse itself is learnable, but the learned prior does not transfer to the representational geometry of the human task.

That cleanly separates two bottlenecks.

---

# 25. Final scientific logic

This experiment should determine whether the previous failed pretraining result occurred because:

\[
\boxed{\text{the SRN cannot learn compositional reuse at all}}
\]

or because:

\[
\boxed{\text{the previous ecology demanded an unrealistically abstract meta-learning rule}}.
\]

The intended progression is:

\[
\text{stable semantics}
\rightarrow
\text{surface variation}
\rightarrow
\text{factor rebinding}
\rightarrow
\text{fully abstract relation}.
\]

Only after identifying the highest abstraction level that the SRN can learn should that prior be tested on the human A/B/Mixed/Novel task.
