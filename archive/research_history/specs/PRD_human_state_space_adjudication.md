# PRD: Human State-Space Adjudication
## Do Familiar A/B Transition Costs Require Separate Skill Memories, or Can Shared Skill + Persistent Context-Specific Expression Explain Them?

## 0. Objective

Before changing the neural-network architecture again, test a more basic assumption in the human data:

> Do the sustained A/B transition costs actually require separate context-specific sequence memories?

The existing state-space family already compares:

```text
Lump   = one learning state shared across contexts
Cross  = two context-specific learning states with partial cross-updating
Split  = two context-specific learning states with no/near-zero cross-updating
```

Those models attribute sustained A/B behavioral differences primarily to **how learning is partitioned across contexts**.

This PRD adds a genuinely different hypothesis:

```text
Shared skill + persistent context-specific expression
```

Under this account, the abstract sequence can be learned largely or entirely in a shared state, while context persistently changes how that skill is expressed at each transition.

This is **not a switch-cost model**. There is no transient “just switched” penalty. Context-dependent expression is allowed to remain different throughout the block.

The key scientific question is:

\[
\boxed{
\text{Does familiar A/B behavior require separate skill memories?}
}
\]

or can it be explained by:

\[
\boxed{
\text{shared sequence learning}
+
\text{persistent context-conditioned realization/expression}
}
\]

This analysis must use **familiar A/B data only** for model fitting and model selection.

Mixed, Novel, and NoContext outcomes remain completely held out from the primary adjudication.

---

# 1. Why this test matters

The neural-network program has repeatedly found a differentiation–transfer frontier:

```text
strong contextual specialization -> poor Mixed/Novel recombination
strong shared/reusable structure -> weak familiar A/B splitting
```

Before engineering a new learning rule, determine whether the human familiar data truly imply that the **sequence memory itself** is split.

If familiar behavior is equally or better explained by a shared sequence representation plus context-specific persistent expression, the neural-network target changes substantially:

```text
do not force the whole sequence representation to split
```

Instead target:

```text
shared sequence dynamics
+
context-conditioned execution / realization dynamics
```

If the existing Cross/Split memory models remain decisively superior under strong predictive tests, then genuine memory partitioning remains the appropriate target.

# 5. Existing model family

Re-run the existing models unchanged so all comparisons are generated by the same executable pipeline.

## M0 — Lump

One shared learning state:

\[
\mathbf{s}_{n}
\]

updated by every familiar sequence regardless of context.

Conceptually:

\[
\mathbf{s}_{n+1}
=
A_s\mathbf{s}_{n}
+
B_s\mathbf{u}_{n}.
\]

Observation:

\[
\mathbf{y}_{n}
=
\boldsymbol{\mu}
-
\mathbf{s}_{n}
+
\boldsymbol{\epsilon}_{n}.
\]

Context does not determine which memory is expressed.

---

## M1 — Cross / partially shared context-specific learning

Two context-specific skill states:

\[
\mathbf{s}_{A,n},\qquad
\mathbf{s}_{B,n}.
\]

Practice in the active context primarily updates its own state and partially updates the other state.

Use the exact historical Cross implementation.

Conceptually, for an A exposure:

\[
\mathbf{s}_{A,n+1}
=
f(\mathbf{s}_{A,n},e_n)
\]

\[
\mathbf{s}_{B,n+1}
=
f_{\rho}(\mathbf{s}_{B,n},e_n)
\]

with:

\[
0<\rho<1.
\]

---

## M2 — Split

Two context-specific states with no or minimal cross-updating.

Use the exact historical Split implementation.

Conceptually:

\[
\rho=0.
\]

# 6. New Model M3 — Shared Skill + Static Persistent Expression

This is the most important new competitor.

There is only one learned sequence state:

\[
\mathbf{s}_n.
\]

Every A and B repetition improves this shared sequence state.

Context does **not** select a different sequence memory.

Instead, A and B have persistent transition-specific expression terms:

\[
\boldsymbol{\delta}_A,\qquad
\boldsymbol{\delta}_B.
\]

Observation:

\[
\mathbf{y}_n
=
\boldsymbol{\mu}
-
\mathbf{s}_n
+
\boldsymbol{\delta}_{c_n}
+
\boldsymbol{\epsilon}_n.
\]

These context effects are sustained.

They do not decay after the first sequence of a block.

They are not functions of:

```text
time since switch
first-sequence status
block onset
```

The first sequence remains excluded exactly as in the historical analysis.

## Identification constraint

Center context effects:

\[
\boldsymbol{\delta}_A
=
+\frac{1}{2}\mathbf{d}
\]

\[
\boldsymbol{\delta}_B
=
-\frac{1}{2}\mathbf{d}.
\]

This prevents the context term from being absorbed arbitrarily into the transition intercept.

---

# 7. M3 parameterizations

Test two prespecified versions.

## M3a — low-dimensional persistent expression

Use a rank-1 context profile:

\[
d_k
=
\gamma w_k
\]

where:

```text
γ = overall A/B expression separation
w_k = normalized seven-transition profile
```

Constrain:

\[
\|\mathbf{w}\|_2=1.
\]

This asks whether a compact context-conditioned execution profile explains the sustained costs.

## M3b — transition-specific persistent expression

Allow:

\[
d_k
\]

for all seven transitions, with hierarchical shrinkage toward zero.

This is the more flexible expression model.

Use shrinkage so it cannot win merely by adding seven unregularized offsets.

Primary interpretation should prioritize M3a when predictive performance is comparable.

---

# 8. New Model M4 — Shared Skill + Learned Persistent Expression State

M3 assumes the context-specific realization is stable across familiar training.

M4 asks whether the underlying sequence is shared while the **context-specific expression layer itself adapts with experience**.

The sequence state remains fully shared:

\[
\mathbf{s}_{n+1}
=
A_s\mathbf{s}_n+B_s\mathbf{u}_n.
\]

Add a low-dimensional context-specific execution state:

\[
q_{A,n},\qquad q_{B,n}.
\]

Only the active context's execution state is updated on that exposure.

For an A exposure:

\[
q_{A,n+1}
=
A_q q_{A,n}
+
B_q r_n
\]

\[
q_{B,n+1}
=
A_q q_{B,n}.
\]

Observation:

\[
y_{n,k}
=
\mu_k
-
s_{n,k}
+
w_k q_{c_n,n}
+
\epsilon_{n,k}.
\]

Here:

```text
s_n,k = shared sequence skill
q_c,n = context-specific realization/execution state
w_k = fixed learned transition-loading profile
```

This model has a crucial structural constraint:

> Context-specific learning is low-dimensional and enters only through the expression pathway.

It does **not** maintain a separate seven-transition sequence-memory vector for A and B.

This is what makes it theoretically different from the historical Split model.

---

# 9. M4 interpretation

M4 represents:

\[
\boxed{
\text{shared sequence knowledge}
+
\text{context-specific persistent realization}
}
\]

rather than:

\[
\boxed{
\text{two independently learned sequence memories}
}
\]

The context-specific realization can persist and evolve across training, so it can explain sustained transition costs without invoking a transient switching mechanism.

No switch-decay term is allowed.

---

# 10. Diagnostic Model M5 — Shared + Context-Specific Memory Decomposition

Implement only as an identifiability diagnostic.

Define:

\[
\mathbf{x}_{c,n}
=
\mathbf{s}_n
+
\boldsymbol{\eta}_{c,n}.
\]

Both:

```text
shared component s
context-specific component η_c
```

can learn.

Observation:

\[
\mathbf{y}_n
=
\boldsymbol{\mu}
-
\mathbf{s}_n
-
\boldsymbol{\eta}_{c_n,n}
+
\boldsymbol{\epsilon}_n.
\]

This is conceptually attractive but may be mathematically equivalent or nearly equivalent to a reparameterized Cross model.

Therefore:

> Do not interpret M5 mechanistically unless model-recovery analyses show that it is distinguishable from Cross/Split with the actual experimental design.

M5 is not a primary candidate model.

# 14. Forward-chaining validation

Because this is a learning trajectory, random observation-level CV is inappropriate.

Use sequential validation.

Recommended folds:

```text
fit early familiar blocks -> predict next block
fit through next block -> predict following block
...
```

For each held-out block:

1. parameter estimates come only from preceding data;
2. initialize latent states from the fitted history;
3. generate one-step-ahead predictions through the held-out block;
4. latent states may update sequentially from observations if that is part of the model's learning rule;
5. parameters remain frozen.

Report:

```text
held-out log likelihood
held-out RMSE
held-out profile correlation
```

per participant and model.

# 20. Primary decision logic

## Outcome A — M3 static expression matches/beats Cross/Split

Interpretation:

> Familiar A/B behavior does not require separate skill memories. A shared learned sequence plus persistent context-conditioned expression is sufficient.

Neural-network implication:

```text
target shared sequence representation + context-conditioned execution/readout
```

rather than forcing the whole recurrent state to split.

## Outcome B — M4 learned expression clearly beats M3 and Cross/Split

Interpretation:

> Humans may share the abstract sequence while learning context-specific persistent execution/realization states.

Neural-network implication:

```text
shared task core
+
learnable context-specific realization layer
```

is the next mechanism to test.

## Outcome C — Cross/Split decisively beat M3/M4 and recovery is strong

Interpretation:

> Sustained human costs genuinely require context-specific learning states under the tested model class.

Neural-network implication:

Focus on a learning principle that partitions memory while preserving shared structure.

Candidate future tests:

```text
context-gated plasticity
context-specific sensorimotor prediction
structured factorized memory
```

## Outcome D — Cross/Split and M4 are empirically indistinguishable

Interpretation:

> Existing familiar behavior does not identify whether context dependence resides in memory or expression.

This is scientifically important.

Do not claim separate skill memories solely from the state-space fit.

Neural-network implication:

Prefer the model with stronger independent support from Mixed/Novel/internal representations, not familiar RT alone.

## Outcome E — Hybrid M5 wins but cannot be recovered from Cross

Do not interpret the decomposition.

Report:

```text
behavior requires at least two latent components,
but their memory-vs-expression locus is not identifiable.
```

---

# 21. Secondary decision: simplicity

If two models have effectively equivalent held-out predictive performance:

```text
Δ held-out log likelihood within uncertainty
```

prefer the model with:

```text
fewer effective parameters
lower-dimensional context-specific state
cleaner identifiability
```

Do not prefer a more elaborate hybrid merely because its in-sample likelihood is marginally higher.
