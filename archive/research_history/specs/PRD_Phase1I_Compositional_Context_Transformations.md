# PRD — Phase 1I: Compositional Context Transformations and Separated Credit Assignment

## 0. Purpose

Implement a narrow mechanistic test of the following account:

> The SRN contains reusable sequence structure, while context changes how that structure is expressed. A and B can therefore produce strongly separated states and nearly orthogonal learning updates, yet a cue containing both familiar contexts can still produce an intermediate/composite transformation of the same underlying sequence structure.

The key unresolved question is **not** whether A and B are separated. They are. It is:

> **Can the context transformations induced by A and B combine when both familiar cues are present, even though learning in A transfers very little to B?**

This phase should directly distinguish:

1. **shared sequence structure + compositional context control**, from
2. **fully independent A/B memories**, from
3. **a compositional target that exists but is not naturally generated by the recurrent dynamics**.

This is primarily a **frozen-network mechanistic analysis plus acute causal intervention**. Do not introduce a new architecture, new ecology, adapters, or additional training by default.

---

# 1. Scientific motivation

The current evidence produces an apparent paradox:

- High-scale SRNs develop strong A/B representational separation.
- High-scale A/B gradients are almost orthogonal, and one-step learning shows much stronger within-context than cross-context improvement.
- Yet the human Mixed condition lies between A and B.
- Earlier SRN interventions show that a shared/composite sequence state can substantially rescue Mixed performance.
- Novel and NoContext remain much harder and often lie far off the familiar A/B task-space path.

A clean way to reconcile these facts is to separate **forward representation** from **backward credit assignment**.

For a sequence transition \(k\), write a schematic representation as

\[
h_{c,k} = T_c(s_k),
\]

where

- \(s_k\) is reusable sequence structure,
- \(c\) is context,
- \(T_c\) is the transformation induced by context.

A and B may therefore produce

\[
h_{A,k}=T_A(s_k),
\qquad
h_{B,k}=T_B(s_k),
\]

while their learning gradients satisfy

\[
g_A^\top g_B \approx 0.
\]

Thus **shared content does not require shared learning**.

The Mixed cue can produce an averaging-like behavioral state if the context control itself composes:

\[
T_{\mathrm{Mixed}}(s_k)
\approx
\operatorname{Compose}(T_A,T_B)(s_k).
\]

For the actual SRN, context enters through the recurrent update, so this must be tested at two levels:

\[
h_t(c)
=
\tanh\!\left(
W_{\mathrm{seq}}x_t
+
W_{\mathrm{ctx}}c
+
W_h h_{t-1}
+
b
\right).
\]

The cue contribution is linear **before** the tanh, but the hidden state and recurrent rollout need not remain compositional after the nonlinearity and recurrence.

That gives the main decomposition for this phase:

1. **Cue-drive composition** — what does the input encoding guarantee?
2. **Matched-state one-step composition** — does composition survive the tanh when history is held fixed?
3. **Recurrent composition** — does it survive a full sequence rollout?
4. **Causal sufficiency** — does forcing the predicted composite state improve Mixed behavior?
5. **Probe specificity** — can the same synthetic composite control rescue Novel/NoContext?
6. **Learning/representation decoupling** — can composition coexist with nearly orthogonal A/B learning gradients?

# 2. Primary hypotheses

## H1 — Familiar cue drives compose at the input/preactivation level

Let \(c_A,c_B,c_M,c_0\) denote the actual encoded context vectors for A, B, Mixed, and the neutral/zero-context condition.

Before any behavioral analysis, solve the **encoding identity**

\[
c_M
=
c_0
+
\alpha_A(c_A-c_0)
+
\alpha_B(c_B-c_0)
+
r_c.
\]

The coefficients \(\alpha_A,\alpha_B\) must be determined **only from the cue encoding**, never from Mixed behavior or loss.

For literal independent A+B cue channels, the expected solution may be approximately

\[
\alpha_A=\alpha_B=1.
\]

For an interpolated encoding, it may instead be

\[
\alpha_A=\alpha_B=\tfrac12.
\]

Do not assume either in code.

The corresponding context preactivation is

\[
p(c)=W_{\mathrm{ctx}}c.
\]

The same encoding relationship should hold in preactivation space up to numerical precision:

\[
p_M
\approx
p_0
+
\alpha_A(p_A-p_0)
+
\alpha_B(p_B-p_0).
\]

This is primarily a **sanity check / architecture audit**, not the scientific result.

---

## H2 — Mixed survives the nonlinear transformation better than Novel/NoContext

For a fixed pre-context hidden state \(h^{-}\) and the exact same sequence token \(x_k\), branch the network under A, B, Mixed, Novel, and neutral context.

Define

\[
h_k(c;h^-)
=
\tanh(
a_k(h^-)+W_{\mathrm{ctx}}c
),
\]

where

\[
a_k(h^-)
=
W_{\mathrm{seq}}x_k+W_hh^-+b.
\]

Define the cue-derived composite prediction

\[
\widehat h_{M,k}
=
h_k(c_0)
+
\alpha_A[h_k(c_A)-h_k(c_0)]
+
\alpha_B[h_k(c_B)-h_k(c_0)].
\]

Do the same in centered-logit/task space:

\[
z=C(W_{\mathrm{out}}h+b_{\mathrm{out}}).
\]

Primary prediction:

\[
\|h_M-\widehat h_M\|
\]

and

\[
\|z_M-\widehat z_M\|
\]

should be substantially smaller for Mixed than the corresponding residuals obtained when trying to explain Novel or NoContext using the familiar A/B composite.

This test must use **identical prestates** across cue branches so that the only manipulated variable is context.

---

## H3 — Recurrent rollout determines whether local composition becomes behavioral averaging

A transformation can be compositional for one step but drift off the composite manifold over a recurrent rollout.

Therefore compare:

### Matched-state one-step composition

Same \(h^-\), branch cue only.

### Free recurrent rollout

Same initial hidden state, then let A, B, Mixed, Novel, and NoContext evolve naturally for all seven sequence transitions.

For each transition \(k\), define the cue-derived free-rollout target

\[
\widehat h^{\mathrm{free}}_{M,k}
=
h_{0,k}
+
\alpha_A(h_{A,k}-h_{0,k})
+
\alpha_B(h_{B,k}-h_{0,k}).
\]

Also compute the analogous centered-logit target.

Interpretation:

- **One-step good + rollout good** → context transformation itself composes through recurrence.
- **One-step good + rollout bad** → cue composition exists locally, but recurrent dynamics amplify deviations.
- **One-step bad** → the familiar context transformations are already non-compositional immediately after the nonlinearity.

---

## H4 — The predicted composite context state is causally sufficient for Mixed rescue

For each transition \(k\), construct the cue-derived composite target without using Mixed loss:

\[
h^{\mathrm{comp}}_k
=
h_{0,k}
+
\alpha_A(h_{A,k}-h_{0,k})
+
\alpha_B(h_{B,k}-h_{0,k}).
\]

During a Mixed rollout, patch the hidden state at the correct sequence position toward this target.

Primary intervention:

\[
h'_{M,k}=h^{\mathrm{comp}}_k.
\]

Measure the next-token and full-sequence **raw cross-entropy loss**.

Required controls:

1. **Correct-position composite patch**
2. **Wrong-position composite patch**
3. **Norm-matched orthogonal patch**
4. **A endpoint patch**
5. **B endpoint patch**
6. **No patch**
7. Optional diagnostic: geometric A/B midpoint patch

The primary causal claim is supported only if the correct-position composite patch improves Mixed raw loss substantially more than the matched controls.

---

## H5 — Mixed composition can coexist with low A↔B learning transfer

For every seed, compare:

- A/B gradient cosine,
- actual one-step cross-context learning transfer,
- matched-state composition score,
- free-rollout composition score,
- causal Mixed rescue.

The expected High-network signature is:

\[
\text{low gradient alignment}
\quad+\quad
\text{weak cross-context learning transfer}
\quad+\quad
\text{nonzero compositional forward structure}.
\]

This is the key conceptual dissociation.

The claim is **not** that gradient orthogonality causes composition.

The claim is:

> Forward compositionality and backward learning transfer are separable properties.

---

## H6 — Novel and NoContext fail because they do not naturally instantiate the familiar composite control state

After the Mixed test is complete, apply the exact same cue-derived composite target to Novel and NoContext rollouts.

Do not construct a new target from Novel/NoContext behavior.

Ask:

> If Novel or NoContext are forced into the familiar A+B composite control state, can the already-learned sequence machinery execute the sequence competently?

Two possible outcomes matter.

### Rescue

If the synthetic composite patch strongly improves Novel/NoContext:

> Their failure is largely a **control-state generation problem**. The downstream sequence machinery is capable of using the composite state, but these cues do not naturally evoke it.

### No rescue

If Novel/NoContext remain poor:

> Their failure is deeper than the absence of the familiar composite control signal; they induce additional off-axis/recurrent states that the simple familiar composition cannot repair.

This test directly connects the Mixed result to the unresolved Novel/NoContext transfer problem.

# 5. Phase B — Matched-state context branching

## Goal

Isolate the immediate context transformation from recurrent history.

## Procedure

For every:

- seed,
- registered checkpoint,
- external sequence,
- transition \(k=1,\dots,7\),
- source prestate type,

save a pre-context hidden state \(h^-_k\).

Use at least two prestate sources:

1. prestate reached under A,
2. prestate reached under B.

Optional third diagnostic:

3. neutral/NoContext prestate.

From the **same exact \(h^-_k\)** branch one step under:

- A
- B
- Mixed
- NoContext
- Novel1
- Novel2
- Novel3
- Novel4

No parameter update may occur.

## Metrics

For hidden space:

\[
E^{h}_{M,k}
=
\frac{
\|h_{M,k}-\widehat h_{M,k}\|
}{
\|h_{A,k}-h_{B,k}\|+\epsilon
}.
\]

For task space:

\[
E^{z}_{M,k}
=
\frac{
\|z_{M,k}-\widehat z_{M,k}\|
}{
\|z_{A,k}-z_{B,k}\|+\epsilon
}.
\]

Also report unnormalized residuals.

For Novel and NoContext, compute the same residual relative to the familiar composite prediction.

## Additional diagnostic: nonlinearity interaction

Because the cue contribution is linear before the tanh, calculate:

\[
I_k
=
h_{M,k}
-
\left[
h_{0,k}
+
\alpha_A(h_{A,k}-h_{0,k})
+
\alpha_B(h_{B,k}-h_{0,k})
\right].
\]

Plot \(\|I_k\|\) over sequence position.

This directly measures how much the tanh destroys cue superposition at matched state.

# 8. Mandatory causal controls

## C1. Wrong-position composite patch

Use the composite target from a different sequence position.

Use a deterministic derangement so no target is accidentally matched to its own position.

## C2. Norm-matched orthogonal patch

Let

\[
\Delta_k
=
h^{\mathrm{comp}}_k-h_{M,k}.
\]

Construct

\[
\Delta_k^\perp
\perp
\Delta_k,
\qquad
\|\Delta_k^\perp\|
=
\|\Delta_k\|.
\]

Apply

\[
h'_{M,k}=h_{M,k}+\Delta_k^\perp.
\]

Use deterministic seed-specific orthogonalization.

## C3. A endpoint patch

Patch to \(h_{A,k}\).

## C4. B endpoint patch

Patch to \(h_{B,k}\).

## C5. No patch

Canonical baseline.

## C6. Optional midpoint diagnostic

\[
h^{\mathrm{mid}}_k
=
\frac12(h_{A,k}+h_{B,k}).
\]

This is **not** the primary target unless the cue encoding audit shows that the actual Mixed cue is a midpoint encoding.

# 14. Decision logic

## Outcome A — Full compositional-context support

Observed pattern:

- Mixed cue has a valid familiar-cue decomposition.
- Matched-state Mixed residual is small.
- Free-rollout Mixed residual remains small/moderate.
- Correct composite patch causally improves Mixed.
- Wrong-position and orthogonal controls do not.
- High networks retain low A/B gradient alignment.

Interpretation:

> A and B share reusable sequence structure, context applies different transformations, the two familiar context signals can compose when jointly present, and learning remains insulated because A/B credit assignment is nearly orthogonal.

## Outcome B — Local composition, recurrent failure

Observed pattern:

- Matched-state composition is good.
- Free-rollout composition deteriorates strongly across transitions.
- Repeated correct-position composite patch rescues Mixed.

Interpretation:

> The input/context transformation is compositional, but recurrent dynamics fail to preserve the composite state.

## Outcome C — Target exists but is not naturally generated

Observed pattern:

- Baseline Mixed is poorly predicted by the cue-derived composition.
- Composite state patch strongly rescues Mixed.
- Controls fail.

Interpretation:

> A useful composite state exists and is sufficient, but the High network's natural Mixed dynamics do not construct it.

## Outcome D — Mixed composition is not supported

Observed pattern:

- Mixed is not more composition-like than Novel/NoContext.
- Composite patches do not selectively rescue Mixed.
- Controls perform similarly.

Interpretation:

> The human averaging phenomenon should not be explained using this context-composition mechanism in the current SRN.

Stop adding complexity to this mechanism.

## Outcome E — Synthetic composite rescues Novel/NoContext

Interpretation:

> Novel/NoContext failure is primarily a failure to evoke the familiar compositional control state. The downstream sequence representation is capable of supporting competent behavior.

## Outcome F — Synthetic composite does not rescue Novel/NoContext

Interpretation:

> Novel/NoContext induce a deeper off-axis or recurrent mismatch. Their transfer problem is not solved by supplying the familiar A+B control state alone.

# 15. Data firewall

The composition mechanism must not be fit to held-out probe behavior.

## Forbidden

- choosing \(\alpha_A,\alpha_B\) to minimize Mixed loss,
- choosing patch strength from Mixed loss,
- selecting sequence positions because they maximize Mixed rescue,
- choosing Novel cue variants after looking at outcomes,
- using Mixed/Novel/NoContext performance to select a checkpoint,
- training any parameter on probe conditions.

## Allowed

- deriving cue coefficients from the known input encoding,
- using A/B/neutral hidden trajectories to construct the composite target,
- evaluating all probes after target construction is frozen,
- reporting probe-specific outcomes.

# 20. Paper-level interpretation if supported

The intended claim is narrower than “A and B memories are averaged.”

A supported result would justify something closer to:

> The network can preserve common sequence structure while context strongly reconfigures its expression and its learning geometry. Familiar contexts A and B induce nearly orthogonal credit-assignment directions, limiting learning transfer between them. However, when the two familiar context cues are jointly present, their control signals can generate a composite transformation of the shared sequence structure, producing an intermediate state without requiring the underlying A and B memories to be merged.

A stronger causal result would allow:

> Forcing the network into the cue-derived composite context state selectively rescued Mixed performance, whereas position-mismatched and norm-matched orthogonal interventions did not.

For Novel/NoContext, only make the stronger claim if the synthetic composite intervention actually rescues them.
