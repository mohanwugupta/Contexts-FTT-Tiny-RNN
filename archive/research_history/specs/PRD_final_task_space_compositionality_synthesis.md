# PRD: Final Mechanistic Synthesis — Formalize Task-Space Compositionality, Audit Phase 1C, and Produce Paper-Ready Results

## 0. Goal

Do **not** train any new model family.

This PRD converts the completed Phase 1C results into the final mechanistic analysis for the paper.

The implementation should answer:

> What representational property allows a model to preserve strong familiar A/B context splitting while also transferring to an ambiguous Mixed context?

The current working answer is:

> Strong context splitting can coexist with transfer if the **task-relevant projection** of the hidden state follows an approximately compositional path between familiar A/B solutions.

This PRD has four jobs:

1. **Audit and reconcile the Phase 1C outputs** so all labels, selected cells, and summary statistics are internally consistent.
2. **Formalize the mechanism mathematically** in a compact task-space framework.
3. **Build a seed-level synthesis** that shows whether the result is a continuous spectrum or driven by a few special seeds.
4. **Generate paper-ready figures, tables, and text-ready numerical summaries** with mandatory sequence-level time series retained.

No new architecture search, ecology, pretraining curriculum, or extra human modeling should be added here.

## 4. Formal task-space definition

Let the SRN hidden state at sequence position \(k\) under context cue \(c\) be:

\[
h_k(c)\in\mathbb R^d.
\]

Let the frozen output map be:

\[
\ell_k(c)=W_{out}h_k(c)+b.
\]

Because softmax is invariant to adding the same scalar to all logits, define the centering matrix:

\[
C
=
I
-
\frac{1}{m}\mathbf 1\mathbf 1^\top,
\]

where \(m\) is the number of output classes.

Define the **task-space representation**:

\[
\boxed{
z_k(c)
=
C\ell_k(c)
=
C(W_{out}h_k(c)+b)
}
\]

This is the primary representational object.

Equivalent hidden-space form:

\[
z_k(c)=CW_{out}h_k(c)+Cb.
\]

Since \(Cb\) is fixed, differences are governed by:

\[
CW_{out}h_k(c).
\]

## 5. Formal A/B interpolation path

Define interpolated context cue:

\[
c_\lambda
=
(1-\lambda)c_A+\lambda c_B,
\qquad
\lambda\in[0,1].
\]

Define familiar endpoint task states:

\[
z_{k,A}=z_k(c_A),
\qquad
z_{k,B}=z_k(c_B).
\]

Define the formal endpoint-linear task-space path:

\[
\boxed{
z_k^*(\lambda)
=
(1-\lambda)z_{k,A}
+
\lambda z_{k,B}
}
\]

This is **not** a claim that the full hidden state must be linear.

The full hidden state may satisfy:

\[
h_k(c_\lambda)
\neq
(1-\lambda)h_k(c_A)+\lambda h_k(c_B).
\]

The hypothesis constrains only task-relevant geometry.

---

## 6. Task-space compositional error

For each sequence position:

\[
e_k(\lambda)
=
z_k(c_\lambda)-z_k^*(\lambda).
\]

Define sequence-level compositional error:

\[
\boxed{
E_{task}(\lambda)
=
\frac{1}{K}
\sum_{k=1}^{K}
\|e_k(\lambda)\|_2^2
}
\]

where \(K=7\) trained next-token transitions.

Also compute normalized error:

\[
\boxed{
R_{task}(\lambda)
=
\frac{
E_{task}^{fine}(\lambda)
}{
E_{task}^{baseline}(\lambda)+\epsilon
}
}
\]

At Mixed:

\[
R_{task}^{Mixed}=R_{task}(0.5).
\]

Interpretation:

```text
1.0 = unchanged from split High baseline
0.0 = reaches formal endpoint-linear task path
```

This is the primary formal path metric.

---

## 7. Hidden-state decomposition

Let \(P_{out}\) be the projector onto the row space of \(W_{out}\), and:

\[
P_{null}=I-P_{out}.
\]

Decompose:

\[
h_k(c)=P_{out}h_k(c)+P_{null}h_k(c).
\]

Define:

\[
E_{out}(\lambda)
=
\frac1K
\sum_k
\|
P_{out}h_k(c_\lambda)
-
[(1-\lambda)P_{out}h_k(c_A)+\lambda P_{out}h_k(c_B)]
\|^2
\]

and:

\[
E_{null}(\lambda)
=
\frac1K
\sum_k
\|
P_{null}h_k(c_\lambda)
-
[(1-\lambda)P_{null}h_k(c_A)+\lambda P_{null}h_k(c_B)]
\|^2.
\]

Primary theoretical point:

```text
E_out matters for behavior.
E_null need not be small.
```

Do not collapse these into one whole-hidden linearity score.

---

## 8. Familiar context splitting metric

Define familiar hidden separation:

\[
\boxed{
S_{AB}
=
\frac1K
\sum_k
\|h_k(c_A)-h_k(c_B)\|_2
}
\]

Normalize to the source High checkpoint:

\[
R_{split}=S_{AB}^{fine}/S_{AB}^{baseline}.
\]

Primary preservation criterion remains:

```text
0.90 <= R_split <= 1.10
```

Do not redefine this threshold.

---

## 9. Endpoint drift

Define:

\[
D_h
=
\frac{
RMSE([h_A,h_B],[h_A^0,h_B^0])
}{
S_{AB}^{baseline}+\epsilon
}.
\]

Define task-space endpoint drift:

\[
D_z
=
\frac{
RMSE([z_A,z_B],[z_A^0,z_B^0])
}{
\|z_A^0-z_B^0\|+\epsilon
}.
\]

Report both.

The key scientific question is whether:

\[
R_{task}^{Mixed}\downarrow
\]

can occur while:

\[
D_h\approx0,
\qquad
R_{split}\approx1.
\]

## 11. Causal rescue formalization

For each seed:

```text
L0 = baseline High Mixed loss
Lpatch0 = baseline High output-only patched Mixed loss
Lfine = fine-tuned correct-path Mixed loss
Lfine_patch = post-finetuning output-only patched Mixed loss
```

Define available rescue:

\[
A_{rescue}=L_0-L_{patch0}.
\]

Define learned rescue:

\[
L_{rescue}=L_0-L_{fine}.
\]

Define per-seed rescue fraction:

\[
\boxed{
F_{rescue}
=
\frac{L_0-L_{fine}}{L_0-L_{patch0}}
}
\]

Define remaining patch gap:

\[
\boxed{
G_{remain}=L_{fine}-L_{fine,patch}
}
\]

Also normalize:

\[
G_{ratio}
=
\frac{L_{fine}-L_{fine,patch}}{L_0-L_{patch0}}.
\]

Save per-seed values first.

Never infer per-seed rescue from ratios of means.

## 13. Seed-level selection rule

For each seed, identify the **best stable correct-path cell** using only:

1. endpoint stability;
2. A/B separation preservation;
3. familiar loss preservation;
4. smallest normalized task-path residual.

Do **not** use Mixed behavior to pick the seed-specific cell.

Algorithm:

```text
eligible =
    endpoint_hidden_drift <= 0.10
    AND endpoint_logit/task drift <= preregistered tolerance
    AND 0.90 <= AB_separation_ratio <= 1.10
    AND familiar_loss_ratio <= 1.10
```

Then among eligible cells choose:

```text
minimum normalized task/logit path residual
```

Tie-break:

```text
smaller alpha
then stronger anchor
then deterministic cell order
```

If no eligible cell exists:

```text
best_stable_cell = NA
```

Do not relax thresholds.

## 22. Formal proposition-style statement

Generate a markdown section with the following logic.

### Definition

A network has **task-space compositional interpolation** between familiar contexts A and B when:

\[
z_k(c_\lambda)
\approx
(1-\lambda)z_k(c_A)
+
\lambda z_k(c_B)
\]

for task-relevant sequence states.

### Empirical sufficiency claim

Within the tested SRN family:

> Reducing deviation from this task-space path can improve zero-shot Mixed performance while familiar A/B separation and endpoint behavior remain approximately fixed.

### Specificity claim

> Matched task-space displacement in an orthogonal/wrong direction does not produce the same benefit.

### Scope limitation

Do **not** claim:

```text
humans literally encode linear task-space vectors
the formal path is necessary
all split SRNs can be retrofitted
developmental ecology is known
```

## 29. Required final conclusion logic

The report should distinguish three levels of claim.

### Supported if current results survive audit

#### Claim A — Behavioral usefulness
Moving toward the formal task-space path improves held-out Mixed behavior.

#### Claim B — Sufficiency in at least a subset of split SRNs
Some split SRNs can be moved close to the formal path while preserving familiar endpoints, and this nearly exhausts the previous patching rescue.

#### Claim C — Directional specificity
Matched movement in a wrong task-space direction does not produce equivalent improvement.

### Not established

#### Necessity
The formal task-space path may not be the only solution.

#### Universality
Not every split seed can necessarily be retrofitted.

#### Human neural implementation
Human behavior is consistent with the computational constraint but does not identify the same latent geometry directly.
