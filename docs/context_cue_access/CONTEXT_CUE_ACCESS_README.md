# Context cue access: handoff package

Start with **PRD_CONTEXT_CUE_ACCESS_CONTROL.md**. It asks whether a different numeric context cue or short preparatory cue history can access useful recurrent continuation in the frozen High-scale SRNs.

1. Copy **CONTEXT_CUE_ACCESS_SCRATCHPAD_TEMPLATE.md** to `results/context_cue_access/v1/scratchpad.md` before coding.
2. Follow stages S0→S4 with RED→GREEN→REFACTOR tests.
3. Do not train model weights or modify original scientific outputs.
4. Keep S1 current-cue capacity separate from S2 same-final-target history manipulation.
5. Use local finite-horizon input-control sensitivities (S3), **not** autonomous dynamical systems analysis.

Minimum final files: `FINAL_CONTEXT_CUE_ACCESS_REPORT.md`, `RESEARCHER_HANDOFF.md`, per-seed CSVs, Figures A/B (and C when informative), source/manifest hashes, test log and scratchpad.
