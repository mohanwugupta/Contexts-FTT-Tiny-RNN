# Human data retained for historical context

This directory retains the existing cleaned human datasets, including `mixedBreak_clean.csv` and `threeContextsBreak_clean.csv`. They are not inputs to the four computational experiments or the evaluation-only paper freeze. Historical human analysis packages and reports remain available, but this PRD does not select a new human manuscript anchor, refit participants, or collect data. See the earlier infrastructure inventory in `docs/FINAL_EXPERIMENT_INFRASTRUCTURE.md` for the historical mapping.
